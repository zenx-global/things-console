# 断舍离与整理方法论 · 总览与对比

> 本语料库收录了 8 种主流的「整理 / 精简生活」方法论，作为「diu-diu-diu」Mac App 的方法论底座。
> App 的核心功能是：**选择一种方法论 → 自动生成对应的可执行计划模板**。
> 本篇是总览与对比，其余各篇按方法论独立成文。

---

## 一、为什么收录这么多方法论

「断舍离」是本项目的主线，但不同人、不同阶段适合不同方法：

- 有人需要 **感性驱动**（KonMari 心动法）
- 有人需要 **游戏化挑战**（Minimalism 30 天游戏）
- 有人被 **家务长期压垮**（FlyLady 小步骤）
- 有人想整理 **桌面和数字信息**（Zen Habits / GTD）
- 有人想给空间做 **标准化管理**（5S）
- 有人站在 **人生终局** 重新审视拥有物（Döstädning）

App 让你**挑选最契合当下状态的一种**，套用它生成计划模板，而不是把所有方法混在一起。

## 二、8 种方法论一览

| # | 方法论 | 作者/出处 | 一句话定位 | 核心判断标准 | 时间结构 | 主要维度 |
|---|---|---|---|---|---|---|
| 01 | **断舍离** | 山下英子（日） | 通过整理物品来整理内心 | 对「当下的我」是否必要·合适·舒服 | 渐进、日常化 | 物品 + 内心 |
| 02 | **KonMari 怦然心动** | 近藤麻理惠（日） | 一次性彻底整理，心动法则 | 拿在手上，是否怦然心动 | 一次性事件 | 物品 |
| 03 | **极简主义 Minimalism** | The Minimalists（美） | 用更少的东西过更有意义的生活 | 是否为生活「增加价值」 | 30 天挑战 | 物品+关系+信息 |
| 04 | **FlyLady** | Marla Cilley（美） | 用小步骤建立家务惯例，把失控的家拉回正轨 | 进步而非完美 | 31 步 + 每周分区 + 每日惯例 | 家务 + 维持 |
| 05 | **Zen Habits 禅习惯** | Leo Babauta | 少即是多，一次只培养一个习惯 | 是否减少干扰、服务当下要事 | 每月一个习惯 | 习惯+任务+桌面+信息 |
| 06 | **Döstädning 瑞典式死亡整理** | Margareta Magnusson（瑞典） | 以终局视角温柔减负，不给亲人留负担 | 「如果明天我走了，它还有意义吗」 | 余生 / 分阶段 | 物品 + 记忆传承 |
| 07 | **GTD（信息维度）** | David Allen（美） | 把未完成的事移出大脑，达到无压状态 | 是什么 / 可行动吗 / 下一步是什么 | 五步闭环 + 每周回顾 | 任务 + 信息 |
| 08 | **5S 现场管理法** | 丰田生产方式（日） | 从减量到维持的标准化空间管理闭环 | 要与不要 + 三定（定位/定类/定量） | PDCA 循环 | 空间 + 标准化 + 素养 |

## 三、关键维度对比

### 1. 判断标准：「凭什么决定一件物品去留？」

| 方法论 | 判断标准 | 偏理性还是感性 |
|---|---|---|
| 断舍离 | 对「当下的我」是否**必要、合适、舒服** | 偏理性（自我轴） |
| KonMari | 拿在手上是否**怦然心动** | 偏感性（直觉轴） |
| Minimalism | 是否为生活**增加价值** | 偏理性（价值轴） |
| FlyLady | （以维持惯例为主，减物为辅） | 实用主义 |
| Zen Habits | 是否**减少干扰**、服务当下要事 | 偏理性 |
| Döstädning | 「**如果明天我走了**」它是否还有意义 | 偏感性（终局轴） |
| GTD | 是什么 / **可行动吗** / 下一步是什么 | 偏理性（流程轴） |
| 5S | **要与不要** + 三定 | 偏理性（工程轴） |

### 2. 时间结构：「按什么节奏推进？」

- **一次性彻底**：KonMari（一次性事件）、Minimalism 的 Packing Party
- **固定周期挑战**：Minimalism 30 天递增游戏、FlyLady 31 步 + 每周 5 区轮转
- **日常渐进**：断舍离（日常化）、Zen Habits（每月一习惯）
- **长周期 / 终局**：Döstädning（余生分阶段）
- **持续循环**：GTD（五步闭环）、5S（PDCA 循环）

### 3. 适合人群

| 你是… | 推荐方法论 |
|---|---|
| 想重新审视「自我与物品」的关系 | 断舍离 |
| 重视直觉、情感驱动，想要彻底蜕变 | KonMari |
| 喜欢游戏化、需要同伴监督的年轻人 | Minimalism |
| 被家务长期压垮、时间碎片化的妈妈/家庭 | FlyLady |
| 桌面/数字信息混乱的知识工作者 | Zen Habits / GTD |
| 中老年、或想以终局视角盘点人生 | Döstädning |
| 工程思维、想给空间做标准化、家庭/团队协作 | 5S |

## 四、方法论的互补关系

这些方法不是互斥的，它们覆盖了「**减量 → 收纳 → 维持 → 标准化 → 多维度 → 终局**」的完整光谱：

```
减量筛选      断舍离 / KonMari / Minimalism
  ↓
收纳定位      KonMari(竖立) / 5S(整顿-三定)
  ↓
日常维持      FlyLady(惯例) / Zen Habits(习惯) / 一进一出
  ↓
标准化闭环    5S(清洁/素养) / GTD(回顾)
  ↓
维度延伸      断舍离(人际/信息/情绪) / GTD(数字信息) / Zen Habits(桌面/任务)
  ↓
终局盘点      Döstädning
```

App 第一版聚焦「单选一种方法论生成模板」；后续可支持**叠加组合**（如「断舍离 + FlyLady」= 先减量、再用惯例维持）。

## 五、断舍离与其他方法的异同速查

断舍离是本项目的主线，理解它与其他方法的差异尤其重要：

| 对比项 | 断舍离 | 其他方法的不同 |
|---|---|---|
| 主角 | **「我」**（自我轴） | KonMari 也重自我感受；传统收纳重「物品」 |
| 时间轴 | **当下** | Döstädning 是「余生/身后」；KonMari 是「一次性」 |
| 判断标准 | 必要·合适·舒服 | KonMari 是「心动」；Minimalism 是「价值」；5S 是「要与不要」 |
| 整理单位 | 可按区域流动 | KonMari 严格按**类别**（全同类集中） |
| 目的 | 通过物品整理**内心** | FlyLady/5S 重**空间与维持**；GTD 重**任务与信息** |

> 一句话：**断舍离整理的是「我与物品的关系」，最终整理的是「我」。**
