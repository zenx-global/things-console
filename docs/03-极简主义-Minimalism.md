# 03 · 极简主义 Minimalism

> **作者**：Joshua Fields Millburn & Ryan Nicodemus（合称 The Minimalists，美国）
> **一句话定位**：用更少的东西，过更有意义的生活——把时间、精力、金钱腾出来,投入到真正重要的事上。
> **核心判断标准**：这件物品 / 关系 / 承诺,是否在为我的生活「增加价值」？（Does this add value to my life?）

---

## 一、核心理念

### 1. 极简主义是「工具」,不是「目的」

The Minimalists 反复强调一句话:**极简主义本身不是终点,而是一艘渡你过河的船**。它的目的不是「拥有尽量少的东西」,而是通过清理那些不增加价值的物品、关系、承诺,把被占用的**时间、精力、金钱、注意力**重新夺回来,投放到让你真正活得有意义的事情上。

- ❌ 误解:极简 = 苦行僧、空无一物、只剩 100 件物品
- ✅ 正解:极简 = 删掉不增值的部分,为「重要的事」留出空间

### 2. 五大核心价值(The 5 Values)

极简腾出来的空间,要装进这五件事,它们是 The Minimalists 为「有意义生活」给出的具体坐标:

| 价值 | 关键词 | 说明 |
|---|---|---|
| 🩺 **健康 Health** | 身体是容器 | 饮食、睡眠、运动——健康崩了,其他都谈不上 |
| 🤝 **关系 Relationships** | 深度优于数量 | 留下少数滋养你的关系,远离消耗你的 |
| 🔥 **热情 Passions** | 心流与爱好 | 找到不计回报也想做的事(创作、运动、手艺……) |
| 🌱 **成长 Growth** | 持续变化 | 刻意学习、反思、走出舒适区 |
| 🎁 **贡献 Contribution** | 超越自我 | 把自己变好后,回馈他人与社群 |

> 判断一件东西去留的终极追问:**「保留它,会让我离这五件事更近,还是更远?」**

### 3. 「用更少,过更有意义」(Love People, Use Things)

The Minimalists 的一句招牌:**Love people and use things, because the opposite never works**(爱人,用物——反过来永远行不通)。物品是为人服务的工具,当人反过来被物品占有、维护、收纳、焦虑时,价值关系就颠倒了。

## 二、关键法则与工具

### 1. 增加价值判断法(Does this add value?)🎯

整个方法论的「单一判断轴」。拿起任意一件物品(或一段关系、一项订阅、一个承诺),只问一个问题:

> **「它是否在为我的生活增加价值?」**

- **是** → 保留,并好好使用
- **否** → 感谢它曾经的陪伴,然后放手(捐赠 / 卖掉 / 回收 / 丢弃)
- **不确定** → 用后续的 90/90 法则、边界法做二次过滤

注意「增加价值」由**你自己**定义,不需要对标别人的极简标准。一把旧吉他对你可能是热情,对别人可能是杂物。

### 2. 30 天极简游戏 #minsgame 🎮

The Minimalists 最出圈的玩法,**强烈建议找一个伙伴一起玩**(朋友 / 伴侣 / 室友均可,互相监督 + 阶段庆祝)。

#### 完整规则

- 📅 第 1 天丢弃 **1** 件,第 2 天丢弃 **2** 件……第 N 天丢弃 **N** 件,直到第 30 天丢弃 **30** 件
- ♻️ 「Anything goes」——扔、捐、卖、回收、送人都算,只要让它**离开你的生活**
- 🚫 当天没完成 → 按缺件数累计到次日(压力会迅速变大,所以最好当天清)
- 👥 双人 / 多人对战:当天没完成的人请客 / 发红包 / 做家务
- 📸 拍照打卡,带上 `#minsgame` 标签,获得社群正反馈

#### 累计数学(为什么是 465 件)

等差数列求和:

$$
\text{总数} = 1 + 2 + 3 + \cdots + 30 = \frac{30 \times (1 + 30)}{2} = \frac{30 \times 31}{2} = \mathbf{465}
$$

> 也就是说,**30 天后,你将从生活中清除 465 件物品**。对大多数人而言,这是一次「房屋被掏空一层皮」级别的彻底清理,却完全不痛苦——因为每天的量都很小,你只是被游戏推着走。

#### 怎么玩才不会「断粮」

到第 20 天之后,容易觉得「家里没东西可丢了」,应对策略:

1. **扩大品类**:衣物 → 厨房 → 书籍 → 数字文件(旧邮件、截图、下载文件夹)→ 订阅服务 → 待办清单里的事项
2. **批量切割**:把「一沓旧票据」「一盒旧数据线」按件计数
3. **降级到关系 / 承诺**:取消一个不再服务的会议、退订一个不再看的公众号,也算一件

### 3. Packing Party 打包派对 📦

适合**搬家前 / 一次大整理**的高强度玩法:

1. 🎉 邀请朋友来家里办一场「打包派对」,准备大量纸箱与记号笔
2. 📦 把**家里所有东西**全部装箱、封口(留出极少数绝对必需:牙刷、当季一套衣服、手机充电器)
3. 🏷️ 每个箱子标注类别 + 日期
4. 🔄 接下来 **1–3 周正常生活**——每需要一件东西,就从箱子里取出来,放回它该在的位置
5. ⏳ 设一个截止日(如 21 天)。**截止日之后仍封在箱中的东西**,就是你「不增加价值」的东西——直接整箱捐赠 / 卖掉,**不要再打开翻看**

> 妙处:用「实际行为」证明你真的不需要,绕开大脑的「万一有用」幻觉。比逐件纠结高效得多。

### 4. 90 / 90 法则 ⏱️

对单件物品做去留判断的经验法则,**两问皆「否」即可放手**:

| 问题 | 判断 |
|---|---|
| 过去 **90 天** 内,我**实际用过**它吗? | 否 → 警报 |
| 未来 **90 天** 内,我**确定要用**它吗? | 否 → 放手 |

补充:The Minimalists 也接受 30 天版(更激进)或半年版(更宽松),**90 是默认值,可按品类调整**。季节性物品(冬装、节日装饰)按年度周期评估。

### 5. 边界而非数字(Just-in-Case → Just-for-Me)🚧

The Minimalists **拒绝**「我只拥有 100 件物品」这种数字炫耀——那会变成另一种执念。取而代之,为每类物品设定**个人边界**:

| 类别 | 个人边界(示例) |
|---|---|
| 衬衫 | 不超过 10 件 |
| 马克杯 | 不超过 4 个 |
| 书(已读) | 一个书架放得下 |
| 数字订阅 | 每月总支出 ≤ ¥200 |
| 工作会议 | 每天不超过 3 个 |

边界一旦设定,超出即触发「一进一出」(买入一件,淘汰一件同类)。**边界因人而异,自己说了算**——这是它与「数字极简主义」炫耀性计数的关键区别。

### 6. 紧急情整理法 / 20·20·20 法则(补充)🆘

当面对一团乱麻不知从何下手时:

> **挑出 20 件可在 20 分钟内处理完的东西,移出 20 件可立即丢弃的东西。**

- 20 分钟:防止拖延,逼自己开始
- 20 件可处理:如洗、归位、修好
- 20 件可丢弃:如过期食品、空瓶、旧票据

适合「启动困难户」,先打破静止,再上 30 天游戏或打包派对。

## 三、典型 30 天挑战日程示例(前 7 天)

> 以下为示例,实际可按你家情况调整。核心是**「当天件数 = 当天日期」**。

| Day | 当天清除件数 | 累计清除 | 示例物品 |
|---|---|---|---|
| **Day 1** | 1 | 1 | 过期 1 年的感冒药 1 盒 |
| **Day 2** | 2 | 3 | 破洞袜子 1 双 + 旧数据线 1 根 |
| **Day 3** | 3 | 6 | 不合身的 T 恤 3 件 |
| **Day 4** | 4 | 10 | 过期票据 / 优惠券 4 张 |
| **Day 5** | 5 | 15 | 旧杂志 5 本 |
| **Day 6** | 6 | 21 | 重复的厨房工具(打蛋器、旧锅铲)6 件 |
| **Day 7** | 7 | 28 | 不再玩的桌游 / 装饰品 7 件 |
| … | … | … | … |
| **Day 15** | 15 | 120 | 半程检查:家里明显空了一截 |
| **Day 30** | 30 | **465** | 🎉 全程完成:累计清除 **465 件** |

> 数学确认:`1+2+…+30 = 30×31÷2 = 465`。前 7 天累计 `1+2+3+4+5+6+7 = 28`,半程(15 天)累计 `120`,后 15 天要清 `345` 件——**越到后面越需要扩品类**,这就是为什么建议玩到后期要把数字文件、订阅、关系也纳入计数。

## 四、适合人群

- 🧭 **追求「意义感」的年轻人 / 职场人**:觉得生活被物品和杂事塞满,想重新校准方向
- 🎮 **喜欢游戏化挑战、需要同伴监督的人**:30 天游戏的机制专治拖延和半途而废
- 📦 **搬家、跳槽、分手、结婚等人生转折期**:需要一次性重置物理与心理空间
- 💸 **被消费主义 / 订阅服务榨干的人**:想从「买买买」循环里跳出来
- 📱 **数字杂物过载者**:截图、邮件、App、订阅、群消息——Minimalism 把这些也纳入「物品」
- 🧑‍🤝‍🧑 **情侣 / 室友 / 家庭**:双人 #minsgame 是低成本的关系磨合工具

## 五、与断舍离的异同

### 对比表

| 维度 | 断舍离(山下英子) | Minimalism(The Minimalists) |
|---|---|---|
| 🌏 **文化基调** | 东方禅意 / 瑜伽哲学(断行·舍行·离行) | 西方实用主义 / 自我成长 |
| 🎯 **判断轴** | 「我」+「当下」(必要 / 合适 / 舒服) | 「价值最大化」(是否增加价值) |
| 📏 **范围广度** | 主攻物品与空间,延伸到关系 | 更广:物品 + 数字 + 关系 + 承诺 + 财务 + 时间 |
| ⚡ **节奏** | 渐进式、日常化、修行感 | 标志性游戏化、强事件化(30 天游戏 / 打包派对) |
| 🔢 **总量控制** | 7·5·1 法则(按可见度) | 边界而非数字(按品类自定) |
| 💭 **哲学终点** | 整理物品 → 整理内心 → 脱离执念 | 删减杂物 → 腾出空间 → 投入五大价值 |

### 共同点

- 都做**减法**,都指向「只留必要 / 有价值的」
- 都强调**脱离执念**,反对被物品占有
- 都认为整理物品 = 整理人生

### 关键差异(一句话)

> 断舍离是**「向内修心」**的东方修行,Minimalism 是**「向外腾位」**的西方工具箱。前者靠**觉知**持续推进,后者靠**游戏机制**持续推进。Minimalism 的游戏化玩法**非常适合 App 做挑战模板**,而断舍离更适合做**长期心态养成**。

## 六、常见误区

- ❌ **误区 1:极简 = 苦行僧,什么都不能有**
  ✅ 真相:极简是「只留增值的」,完全可以保留昂贵的相机、好酒、好咖啡——只要它对你真有意义。
- ❌ **误区 2:追求「我只拥有 N 件物品」的数字炫耀**
  ✅ 真相:The Minimalists 明确反对计数攀比,主张「**边界而非数字**」,自己定自己的标准。
- ❌ **误区 3:只整理实体物品,忽视数字 / 关系维度**
  ✅ 真相:Minimalism 把订阅、App、截图、群消息、会议、人际关系都视为「可极简对象」。
- ❌ **误区 4:一次清完就万事大吉**
  ✅ 真相:极简是**持续代谢**,需要靠「一进一出」+「边界」维持,否则 3 个月就反弹。
- ❌ **误区 5:把伴侣 / 家人的东西也偷偷扔了**
  ✅ 真相:只处理**你自己的**物品;想影响家人,用**邀请**而非**命令**(「要不要一起玩 30 天游戏?」)。
- ❌ **误区 6:把「增加价值」窄化为「有用 / 实用」**
  ✅ 真相:带来快乐、回忆、美感、灵感都算「增加价值」,不必功利。

## 七、App 模板形态(30 天递增挑战清单)

选择「Minimalism」生成计划时,模板生成 **30 天递增挑战清单**,每天任务量 = 当天日期,并附带 **90/90 法则提示**。

### Day 1–5 具体任务示例

- 🟢 **Day 1(清 1 件)**:找一件**过期 / 损坏**的物品丢弃(药品、食品、电池)
- 🟢 **Day 2(清 2 件)**:清理**抽屉里的杂物**(旧票据、空包装、说明书)
- 🟢 **Day 3(清 3 件)**:挑 3 件**一年没穿**的衣物,捐赠或回收
- 🟢 **Day 4(清 4 件)**:清理 4 个**数字杂物**:截图、下载文件、旧邮件、无用 App
- 🟢 **Day 5(清 5 件)**:挑 5 本**不会再看**的书,送人或二手出售
- … 🔁 每日递增,直到 Day 30 清 30 件

### 每个任务卡片附带

> ⏱️ **90/90 法则提示**:过去 90 天用过吗?未来 90 天会用吗?两个「否」→ 放手。
>
> 🎯 **价值追问**:它是否在为我的生活增加价值?(健康 / 关系 / 热情 / 成长 / 贡献)
>
> ♻️ **去处选择**:捐赠 / 二手出售 / 回收 / 丢弃 / 送朋友

### 进度仪表盘

- 📊 累计清除件数 / 465
- 📅 当前连续打卡天数
- 🏅 里程碑:Day 7(28 件)、Day 15(120 件)、Day 21(231 件)、Day 30(465 件 🎉)

## 八、方法论浓缩公式

> **Minimalism = 以「是否增加价值」为单一判断轴 + 用「30 天游戏 / 打包派对 / 90·90 法则」做清除 + 用「边界而非数字」做维持 + 把腾出的空间投入「健康 / 关系 / 热情 / 成长 / 贡献」五大价值——用更少的东西,过更有意义的生活。**
