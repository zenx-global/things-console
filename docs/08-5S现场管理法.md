# 08 · 5S 现场管理法

> **出处**：日本制造业现场管理方法，源自丰田生产方式（Toyota Production System，TPS）。
> **一句话定位**：一套「从减量到定位、从清洁到标准化、最终落到人的素养」的完整空间管理闭环。
> **核心判断标准**：**「要与不要」+「三定（定类 / 定位 / 定量）」**——先用前者减量，再用后者归位。
> **起源说明**：5S 最初是日本制造业在 20 世纪 50–70 年代为提升车间效率、安全与品质而沉淀出的现场管理法；五个步骤的日文罗马拼音均以 **S** 开头（Seiri / Seiton / Seiso / Seiketsu / Shitsuke），故称 5S。后来被广泛移植到办公、医院、学校乃至个人与家庭空间，本篇聚焦后两者。

---

## 一、核心理念

- **源自制造业车间管理**：5S 不是「打扫卫生」，而是丰田生产方式（TPS）底层支撑之一，与精益生产（Lean）、准时制（JIT）一脉相承。它把「现场的整洁有序」当作效率、安全与品质的前提。
- **五步构成完整闭环**：减量 → 定位 → 清洁 → 标准化 → 素养。前三步是「做出来」，第四步是「定下来」，第五步是「坚持住」。任何一步缺位，前功尽弃。
- **最终落到「人」的素养养成**：物品可以一次整理干净，但若人的习惯不变，一周后必然反弹。5S 的终点不是干净的房子，而是**自律的人**。
- **可移植到个人 / 家庭空间**：从车间搬到厨房、书桌、衣柜、储物间，逻辑完全成立——只是「工序」从「装配线」变成「日常生活动线」。

## 二、五个步骤详解

### 1S 整理 Seiri —— 区分要与不要，果断舍弃

- **日文**：整理（Seiri），英文常译 Sort / Sort Out。
- **含义**：将现场（家庭空间）所有物品分为「要」与「不要」，并**果断移除不要的**。注意：这里的「整理」不是「摆放整齐」，而是「**减量决策**」。
- **在个人空间的应用**：把一个区域（如衣柜、抽屉、书架）的全部物品摊开，逐一判断：在用 / 暂不用 / 完全不用。在用的留下并归位；暂不用的设定观察期（红牌作战）；完全不用的舍弃（丢弃、捐赠、二手转卖）。
- **具体操作**：
  1. 选定一个区域，**全部清空**摊在眼前（不看全貌就无法判断）。
  2. 逐件判断「这件我最近 X 个月用过吗？未来会用吗？」。
  3. 三分：**留 / 待定 / 舍**。待定的贴红牌进入暂存区。
  4. 「舍」的当天处理掉，不要拖。
- **示例**：衣柜里有 3 件两年没穿的西装，其中 1 件尺码已不合身 → 直接舍弃；另外 2 件犹豫 → 贴红牌，给 3 个月观察期。

### 2S 整顿 Seiton —— 三定原则，30 秒找到

- **日文**：整頓（Seiton），英文常译 Set in Order / Straighten。
- **含义**：让「要的物品」**各有归属、各就各位**，目标是「**任何人 30 秒内能找到任何一件物品并归位**」。核心工具是**三定：定类、定位、定量**。
- **在个人空间的应用**：同类物品集中存放、固定位置、控制合理存量，让「找东西」和「放回去」都变成零思考动作。
- **具体操作**：
  1. **定类**：按用途分类（如厨房的「烘焙工具」「调料」「餐具」）。
  2. **定位**：每类固定一个存放区，靠近使用点（动线最短）。
  3. **定量**：设定合理存量上下限（如调料最多 2 瓶备用、毛巾最多 5 条）。
- **示例**：把所有充电线集中到一个抽屉，按「手机 / 笔记本 / 其他」分格，每类只保留 2 根，多出的舍弃。

### 3S 清扫 Seiso —— 清除脏污，清扫即检查

- **日文**：清掃（Seiso），英文常译 Shine / Sweep。
- **含义**：彻底清除脏污与故障隐患。5S 的关键理念是「**清扫即检查**」——打扫的过程就是发现问题的过程。
- **在个人空间的应用**：定期清洁，并在打扫时留意异常（冰箱异味、墙角发霉、插座松动、水管渗漏）。
- **具体操作**：
  1. 划分清扫责任区与频次（厨房台面每日、油烟机每月、冰箱内部每周）。
  2. 清扫时**顺便检查**：密封条是否老化、过滤网是否堵塞、过期食品是否还在。
  3. 发现问题立即记录、限期修复，不留隐患。
- **示例**：擦灶台时发现油污堆积处正好是燃气管接头 → 立即检查是否漏气、是否需要更换。

### 4S 清洁 Seiketsu —— 制度化标准化，把前 3S 固化为可视规则

- **日文**：清潔（Seiketsu），英文常译 Standardize / Sustain。
- **含义**：把整理、整顿、清扫的做法**写成规则、变成制度**，让整洁不依赖记忆与心情，而依赖**系统**。
- **在个人空间的应用**：把「谁、什么时候、做什么、做到什么标准」固化成家庭清单或可视规则（标签、定位线、看板）。
- **具体操作**：
  1. 把每个区域的「归位标准」与「清洁频次」写下来（纸质清单或 App 提醒）。
  2. 用目视化工具让规则**看得见**（详见下文「目视化管理」）。
  3. 家庭会议达成共识，让规则成为**共同约定**而非一人指令。
- **示例**：玄关鞋柜门内侧贴一张「鞋柜容纳上限：每人 8 双，超出先舍弃再购入」的标签。

### 5S 素养 Shitsuke —— 养成习惯，全员自律

- **日文**：躾（Shitsuke），英文常译 Sustain / Self-Discipline。
- **含义**：让前 4S 从「形式」变成「习惯」，从「要我做」变成「我要做」。这是 5S 最难、也最重要的一步。
- **在个人空间的应用**：通过每日小复盘、家人互相提醒、定期回访，让规则内化为下意识的动作。
- **具体操作**：
  1. 设定每日「3 分钟归位」仪式（睡前把当天用过的物品放回原位）。
  2. 每周 / 每月做一次 5S 回访（检查红牌暂存区、复核存量上限）。
  3. 对坚持给予正反馈，对偏离温和纠正，不指责。
- **示例**：连续一个月做到「用完即归位」，给自己一个小奖励；偏离时不内疚，复盘原因后重启。

## 三、关键技巧

### 🔴 1. 红牌作战 Red Tag

整理阶段的核心武器，专门对付「拿不准要不要留」的物品。

1. **贴红牌**：对每个「疑似不要」的物品贴一张红牌，写明：物品名、贴牌日期、判断人、暂定期限。
2. **集中暂存区**：把贴红牌的物品集中到一个**专门的暂存箱 / 暂存区**（不要和日常物品混放）。
3. **设期限**：设定观察期（常用 1–3 个月，季节性物品可设 1 年）。
4. **逾期清理**：期限到达时，若该物品**一次都没用过**，立即舍弃——不要再给自己第二次犹豫的机会。

> 红牌的本质是把「**留还是舍的决策**」从「当下情绪」转移到「**时间和数据**」上，用事实代替纠结。

### 📐 2. 三定原则（定类 / 定位 / 定量）

- **定类（Sort by kind）**：同类归一。所有剪刀放一起、所有充电线放一起，避免「到处都是、找不到」。
- **定位（Set location）**：每类一个固定家。遵循「**就近使用点**」原则，减少动线。常用物品在黄金区（伸手可及），不常用物品在高处或深处。
- **定量（Set quantity）**：设定上下限。例如毛巾 3–5 条、保鲜盒 6 个、酱油备用 1 瓶。**超出上限即触发舍弃**，从源头防止复购堆积。

> 三定回答了三个问题：这是哪一类？它住哪里？最多留几个？

### 🏷️ 3. 目视化管理 Visual Control

让状态与规则**一眼可见**，不依赖记忆。

- **标签 Label**：抽屉、收纳盒外侧贴标签，写明内容物与数量。
- **定位线 Tape**：地面或桌面贴定位胶带，标示物品「应该放在这里」的轮廓（车间常用，家庭可简化为收纳格）。
- **颜色编码 Color coding**：用颜色区分类别（如红色=清洁用品、蓝色=工具、绿色=食品）。
- **看板 Kanban**：一张表展示「区域负责人 + 清洁频次 + 上次完成时间」，让进度透明（家庭版可贴冰箱上）。

### 🔄 4. PDCA 循环（5S 不是一次性）

- **Plan 计划**：选定区域、设定目标与频次。
- **Do 执行**：按五步推进整理。
- **Check 检查**：定期回访，红牌暂存区是否清理？存量是否超限？
- **Act 改进**：根据检查结果调整规则（如某类物品总是超量，说明上限设置不合理）。

> 5S 是螺旋上升的循环，不是一次性大扫除。每次循环都让系统更贴合实际。

### 🦺 5. 安全 Safety —— 可选的第 6 个 S

部分企业在 5S 基础上加入**安全（Safety）**，称为 6S。在家庭场景同样重要：

- 清洁用品、药品、刀具、电器**远离儿童可触及区**。
- 检查燃气管线、电源插座、烟雾报警器是否正常。
- 应急包位置固定且全员知晓。

> 安全是 5S 的底线目标：一个整洁的空间，首先必须是一个安全的空间。

## 四、家庭 5S 实施示例（以厨房为例）

| 步骤 | 具体动作 |
|---|---|
| 🔴 **1S 整理** | 把所有橱柜、冰箱、台面物品全部取出；分类判断：在用 / 暂不用 / 不用；过期食品、坏掉的厨具直接舍弃；犹豫的（如只做过一次的烘焙模具）贴红牌放入暂存箱，设 3 个月期限。 |
| 📐 **2S 整顿** | 三定：**定类**——调料 / 餐具 / 锅具 / 烘焙 / 清洁用品分柜存放；**定位**——调料放灶台上方伸手可及、锅具放下柜、清洁用品水槽下；**定量**——调料备用不超过 2 瓶、保鲜盒 6 个、毛巾 5 条。 |
| 🧹 **3S 清扫** | 台面每日擦拭；油烟机滤网每月拆洗；冰箱内部每周清理过期食品；清扫时检查：密封条是否发霉、燃气管接头是否漏气、下水是否通畅。 |
| 📋 **4S 清洁** | 冰箱门贴「调料存量上限表」与「清洁频次表」；橱柜内侧贴标签标明内容物；家庭会议约定「买新必舍旧」原则。 |
| 🧠 **5S 素养** | 每周日晚 10 分钟厨房 5S 回访（检查红牌、复核存量）；饭后立即「用完即归位」；连续达标给家庭小奖励。 |

## 五、适合人群

- **工程师 / 理科思维者**：喜欢系统化、流程化、可视化，享受「定义规则—执行—优化」的快感。
- **想标准化生活的人**：希望家里 / 办公桌 / 工作室达到「**标准化整洁**」，而非「偶尔大扫除后短暂的干净」。
- **家庭 / 团队协作场景**：合租屋、多人家庭、共享工作室——需要共同约定来维持秩序，5S 的可视化规则天然适合协作。
- **反弹型整理者**：整理过很多次但总是反弹的人——5S 的 4S 清洁 + 5S 素养正是针对「反弹」的解药。
- **追求效率与秩序感的人**：把「找东西」「打扫」「采购」从消耗变为流程，腾出时间与精力做更重要的事。

## 六、与断舍离的异同

| 维度 | 断舍离（山下英子） | 5S 现场管理法 |
|---|---|---|
| **起点 / 第一步** | 断（断绝入口）+ 舍（舍弃多余） | 1S 整理（区分要与不要）——两者高度重合 |
| **范围** | 减物 + 内心修练 | 减量 + 定位 + 清洁 + 标准化 + 素养（完整管理闭环） |
| **风格** | 偏哲学、禅意、关注自我与当下 | 偏工程、管理、关注流程与可视规则 |
| **重心** | 重**内心**——通过物品审视自我关系 | 重**空间**——通过系统维持秩序 |
| **可操作性** | 给判断标准（我 / 现在 / 需要），弱于落地流程 | 给落地工具（红牌、三定、目视化、PDCA） |
| **协作适配** | 个人修行为主 | 天然适合团队 / 家庭协作 |
| **终极目标** | 通过减物获得身心自由 | 通过标准化养成自律素养 |

**文字补充**：断舍离的「断 + 舍」基本等于 5S 的第 1 步整理（Seiri），两者在**减量**这一环是同一件事。差异在于：断舍离到此转入**内心修行**，而 5S 继续走完**定位、清洁、标准化、素养**的工程闭环。两者**高度互补**——断舍离解决「为什么减、为谁减」的内在动机，5S 解决「减完之后怎么不反弹」的外在系统。在 App 中，5S 模板天然可以把断舍离作为 1S 整理的判断内核。

## 七、常见误区

- **只做 1S 整理就停**：减完量却没有 2S 整顿归位，物品很快又乱；没有 4S 清洁标准化，两周后反弹。**减量只是起点，不是终点。**
- **把 5S 当成一次性大扫除**：5S 是 PDCA 循环，不是「年底大清洁」。一次性做得很彻底但没有制度化，必然回潮。
- **忽视 4S 清洁的标准化**：很多人享受整理（1S）和归位（2S）的爽感，却跳过 4S 把规则写下来。结果换个人、换个心情，规则就失效了。
- **家人不参与导致反弹**：一个人整理、其他人照旧乱放——这是最常见的失败原因。必须通过家庭会议达成共识，让规则成为**共同约定**，并借助目视化让所有人都能执行。
- **追求完美反而拖延**：等「有大块时间」再做，结果永远不做。5S 主张**小区域、高频次**，从一个抽屉开始也行。
- **把 5S 等同于「扔东西」**：5S 的核心是**该留的留好、该去的去清**，不是无脑丢弃。扔只是手段，建立可持续秩序才是目的。

## 八、App 模板形态（五步标准化模板）

选择「5S」生成计划时，模板按**五个 S** 组织任务，每个 S 含可勾选的具体动作：

- 🔴 **1S 整理（区分要与不要 + 红牌作战）**
  - 选定目标区域，全部清空摊开
  - 逐件判断：在用 / 暂不用 / 不用
  - 不用的当天舍弃（丢弃 / 捐赠 / 转卖）
  - 暂不用的贴红牌，入暂存区，设观察期（1–3 个月）
  - 记录红牌清单（物品 / 贴牌日 / 截止日）

- 📐 **2S 整顿（三定 + 30 秒找到原则）**
  - 定类：同类物品集中
  - 定位：每类固定存放区，靠近使用点
  - 定量：设定每类上下限（如毛巾 3–5 条）
  - 验证：随机抽 5 件物品，30 秒内能否找到并归位
  - 贴标签：抽屉 / 收纳盒外侧标注内容物与数量

- 🧹 **3S 清扫（定期打扫 + 清扫即检查）**
  - 划分责任区与清洁频次（日 / 周 / 月）
  - 执行清扫并记录异常（发霉 / 漏水 / 松动 / 过期）
  - 异常项限期修复，闭环验证
  - 清扫工具本身也归位（拖把 / 抹布 / 清洁剂定点存放）

- 📋 **4S 清洁（制度化标准化 + 目视化）**
  - 把每个区域的归位标准与清洁频次写成清单
  - 制作目视化工具：标签 / 定位线 / 颜色编码 / 看板
  - 家庭会议达成共识，明确负责人
  - 设定回访周期（每周 / 每月检查一次）

- 🧠 **5S 素养（每日自律 + 定期复盘）**
  - 每日「3 分钟归位」仪式（睡前物品归位）
  - 每周 5S 回访（检查红牌暂存区、复核存量上限）
  - 偏离时不内疚，复盘原因后重启
  - 连续达标给予正反馈（自我奖励 / 家庭小庆祝）

## 九、方法论浓缩公式

> **5S = 减量（Seiri）+ 归位（Seiton）+ 清洁（Seiso）+ 标准化（Seiketsu）+ 素养（Shitsuke）**
>
> 一句话：**「该留的留好，该去的去清，每天归位，规则可视，习惯成自然。」**
>
> 判断公式：**留 = 现在 + 我 + 需要**（借鉴断舍离）；**位 = 同类 + 就近 + 定量**（三定）；**持 = 制度 + 目视 + 复盘**（4S+5S）。
