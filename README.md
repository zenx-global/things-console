# Things Console · 个人物品管理工作台

> 一个 macOS 原生 App：用运营「一人公司」的方式管理个人物品——资产有台账、看板有 KPI、库存有预警、处置有行动。

---

## 这是什么

像 CEO 运营公司资产一样运营个人物品（OPC / CEO Stack 思路）：

| 模块 | 公司隐喻 | 做什么 |
|---|---|---|
| 资产看板 | CEO 驾驶舱 | 物品总数、资产总值、待处理提醒、已退役数；风险预警 / 分类价值分布 / 最近录入 |
| 物品台账 | 资产负债表 | 物品档案的增删改查、搜索与状态 / 分类过滤、照片档案 |
| 库存与到期 | 库存与风控 | 到期预警、质保临期提醒、多数量物品快速增减 |
| 数据与备份 | 数据资产安全 | 完全离线本地存储、每日自动备份（保留 10 份）、一键完整备份 / CSV 导出 / 恢复 |
| 整理计划 | 处置行动项目 | 套用一种方法论生成断舍离计划清单，可勾选 / 编辑 / 备注 |
| 方法论库 | 运营 SOP | 8 种「整理 / 精简生活」方法论语料 |
| Excel 台账 | 线下离线报表 | 导出带 ID 列的 .xlsx，在 Excel / Numbers / WPS 中持续维护后一键合并导回 |
| 手机速录 | 移动端录入终端 | Mac 开启局域网服务后，手机扫码录入（可拍照），数据直达本地台账 |
| 箱子清理 | 处置行动指挥部 | 批量建箱、单箱工作台（计时 + 处置流）、出口区带出；手机用 Web 作业页 `/boxes`，Mac 用原生看板 |

### 极速录入（收拾房间模式）

- 台账底部**极速栏**：输入名称按回车即存，自动沿用上次分类 / 位置
- 工具栏「快速录入」（⚡）：回车保存并继续的连续录入面板，本批计数反馈，全程键盘操作
- 新建表单自动预填上次分类 / 位置

### Excel 台账往返

- 「数据与备份」导出带 **ID 列**的 .xlsx（Excel / Numbers / WPS 均可打开）
- 在表格里持续补行、改行，随时导回：按**列名匹配**（与列顺序无关），ID 相同的行更新、无 ID 的行新增，空名称行跳过
- 空单元格 = 清空该值（数量留空保持原值）；整列删除 = 该字段不变；照片不受影响；导入前自动创建快照

### 手机速录（局域网）

- 「手机速录」页一键开启服务，手机连同一 Wi-Fi **扫码即用**
- 名称 / 分类 / 位置 / 数量几秒录入，支持**拍照**（自动压缩），最近录入实时可见
- 页面凭随机密钥访问、仅在本机局域网内可用，数据不经过任何云端

### 数据安全与备份

- 档案存于 `~/Library/Application Support/ThingsConsole/items.json`，原子写入；v1 UserDefaults 数据自动迁移
- 每天首次启动自动备份到 `ThingsConsole/Backups/`，保留最近 10 份；也可手动「立即备份」
- 备份格式 = `items.json` + `boxes.json`（开放 JSON）+ `Photos/` 照片副本，可直接拷到 U 盘 / 网盘，跨机器恢复
- 支持导出 Excel 友好的 CSV（带 BOM），以及从任意备份文件夹一键恢复

风格：左侧菜单 + 右侧功能区的专业控制台布局。

### 物品档案字段

- **基础信息**：名称、分类、存放位置、品牌/型号、状态（在用 / 闲置 / 已退役）
- **价值与购入**：购入单价（小计 = 单价 × 数量）、购入日期、购买渠道、质保到期
- **照片**：多张照片，本地文件存储，列表 / 详情 / 看板展示缩略图
- **数量与到期**：数量、到期日（食品 / 药品 / 耗材）

### 分类体系（按整理最佳实践预设）

参照 KonMari 五大类补齐「文件 / 纪念品」维度、并结合资产管理视角预设 18 个分类（顺序即推荐整理顺序）：

| 维度 | 分类 |
|---|---|
| 穿戴与形象 | 👕 服饰鞋包 · 💄 美妆个护 · 🧴 清洁用品 |
| 空间与家电 | 🛋️ 家具家居 · 📺 家用电器 |
| 电子资产 | 💻 数码电子 · 🔌 数码配件 |
| 饮食与健康 | 🍳 厨房餐饮 · 💊 食品药品 |
| 知识与凭证 | 📚 图书文具 · 📄 文件证件 |
| 活动与陪伴 | 🏀 运动户外 · 🔧 工具设备 · 🧸 母婴玩具 · 🐾 宠物用品 |
| 便携与情感 | 🧳 出行收纳 · 🎁 纪念收藏 |
| 兜底 | 📦 其他 |

- 表单与快速录入的分类下拉里可「＋ 新建分类」，即建即选
- 台账工具栏「⋯ → 管理分类」：重命名 / 换图标 / 删除（物品自动归入「其他」），显示每个分类的物品数
- 分类注册表持久化于 `categories.json`；内置预设只增不删，用户删除的预设不会随升级复活

### ② SwiftUI Mac App（`app/`）
左侧菜单五项（资产看板 / 物品台账 / 库存与到期 / 整理计划 / 方法论库），数据本地持久化，无需后端、无需联网。

- **台账与照片**：UserDefaults(JSON) 存档案，照片落盘 `~/Library/Application Support/ThingsConsole/Photos`，孤儿文件启动时自动回收
- **整理行动**：选方法论 → 自动生成可执行计划模板，勾选 / 加备注

## 技术栈

- **平台**：macOS 14+
- **框架**：Swift + SwiftUI
- **依赖**：纯原生，无第三方库

---

## 构建

```bash
bash app/build.sh        # 产出 app/build/ThingsConsole.app
open app/build/ThingsConsole.app
```

> **构建方式说明**：本机当前只有 Command Line Tools（无完整 Xcode），因此用
> `swiftc` 直接编译 SwiftUI 源码并手工组装 `.app` bundle（见 `app/build.sh`）。
> 注意：CLT 默认 SDK（26.x+）缺少 SwiftUI 宏插件，build.sh 固定用本机的
> `MacOSX15.2.sdk` 编译；装了完整 Xcode 后，可改用 `.xcodeproj` + `xcodebuild`。
