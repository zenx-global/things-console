## 阶段一：方法论语料沉淀（先做）

### 内容（基于已完成的调研，覆盖 8 种方法论）
1. **总览与对比**：8 种方法论一览表、判断标准/时间结构/适合人群对比、如何选择
2. **断舍离**（核心）：断/舍/离定义、瑜伽冲道起源、自我轴+当下时间轴、需要·合适·舒服、7·5·1 法则、一进一出、三分法分类、与传统收纳区别、从物品到人生的多维度延伸
3. **KonMari**：心动法、六大规则、五类别顺序（衣→书→纸→杂物→纪念品）、竖立收纳、感谢仪式
4. **Minimalism**：增加价值、30 天极简游戏、Packing Party、90/90 法则
5. **FlyLady**：闪亮水槽、15 分钟法则、31 步 Baby Steps、5 区轮转、Home Blessing
6. **Zen Habits**：一次一习惯、清空桌面、MIT、ZTD
7. **Döstädning**：终局视角、大件优先、四分类、记忆物品传承
8. **GTD（信息维度）**：五步闭环（收集→厘清→组织→回顾→执行）、2 分钟法则
9. **5S**：整理/整顿/清扫/清洁/素养、红牌作战、三定原则

每篇统一结构：核心理念 / 关键法则与步骤 / 适合人群 / 与断舍离异同 / 关键来源链接。

## 阶段二：SwiftUI Mac App（标准版 MVP）

### 三大功能区（侧边栏导航）

**① 方法论**（学习）
- 浏览 8 种方法论卡片，点开看完整理论（核心理念/法则/适合人群/来源）
- 数据来自内置 Swift 结构体，与 docs 语料保持一致

**② 我的计划**（核心：选方法论 → 生成模板）
- 新建计划流程：输入标题 → 选择一种方法论 → **自动生成对应模板任务清单**
- 任务可增删改、可勾选完成、可加备注/截止日
- 计划进度条（已完成/总数）

**③ 仪表盘**
- 所有计划总览 + 整体进度统计

### 各方法论生成的模板（差异化卖点）
| 方法论 | 模板形态 |
|---|---|
| 断舍离 | 区域流动式减物清单（玄关/客厅/卧室/厨房/书房…），每区域含"需要·合适·舒服"三问 |
| KonMari | 五类别任务流（衣服/书籍/纸张/杂物/纪念品），每类含"是否心动"判断 |
| Minimalism | 30 天递增挑战（Day1 丢 1 件 … Day30 丢 30 件）+ 90/90 判断提示 |
| FlyLady | 31 个 Baby Steps + 每周 5 区轮转任务 |
| Zen Habits | 单习惯清单 + 桌面清空 + MIT 每日三件事 |
| Döstädning | 大件优先 + 保留/捐赠/出售/丢弃四分类清单 |
| GTD | 数字杂物五步整理清单（收件箱/下载夹/桌面…） |
| 5S | 五步模板（整理→整顿→清扫→清洁→素养）+ 红牌作战子任务 |

### 数据模型（SwiftData 本地持久化）
- `Methodology`（内置静态）：id / 名称 / 定位 / 类别 / 理念 / 法则 / 步骤[] / 来源[]
- `Plan`：id / 标题 / methodologyId / 创建时间 / 任务[] 
- `Task`：id / 标题 / 备注 / 是否完成 / 截止日 / 排序 / planId

### 技术要点
- **最低系统**：macOS 14+（SwiftData）
- **依赖**：纯原生，无第三方库
- **构建**：用 `ios_create_app` 同类方式手动生成 Xcode 工程文件；构建用 `xcodebuild`
- **前提**：你机器需装好 Xcode（如未装我会在构建时报错提示）
